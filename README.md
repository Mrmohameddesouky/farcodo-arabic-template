# قالب فاركودو العربي لبلوغر (Farcodo Arabic Blogger Template)

قالب Blogger XML أصلي بالكامل، عربي 100% (RTL)، مكتوب من الصفر دون نسخ أي قالب تجاري.
النسخة الإنجليزية مشروع منفصل ولم تبدأ.

## هيكل المستودع
```
dist/farcodo-arabic-template.xml   القالب النهائي المستقل (يُرفع إلى Blogger)
src/template.src.xml               مصدر القالب (مع علامات @@ تُستبدل عند البناء)
src/farcodo.css | farcodo.js       التنسيقات والسكربت
assets/farcodo-logo-original.png   الشعار الأصلي كما رُفع (دون أي تعديل)
assets/farcodo-symbol-cropped.png  قصّ هندسي فقط (إزالة الهامش الشفاف) بالدقة الأصلية
assets/farcodo-symbol-160.webp     نسخة محسّنة تُضمَّن في القالب
assets/favicon-{32,64,180,192,512}.png
tools/build.py | validate.py       البناء والفحص المحلي
docs/                              التثبيت والإعداد، تقرير الاختبار، المشكلات المعلّقة
```
أعد البناء بعد أي تعديل: `python3 tools/build.py && python3 tools/validate.py`

## التثبيت (على نسخة تجريبية أولاً!)
1. أنشئ مدونة اختبار (أو خذ نسخة احتياطية: القالب ← النسخ الاحتياطي).
2. الإعدادات ← **اللغة** ← العربية، والمنطقة الزمنية المناسبة (يضبط نصوص التعليقات الافتراضية).
3. القالب ← النسخ الاحتياطي/الاستعادة ← **تحميل** ← اختر `dist/farcodo-arabic-template.xml`.
4. الإعدادات ← المقالات: **عدد المقالات في الصفحة الرئيسية = 9** (3 للواجهة العلوية + 6 في القائمة).
5. لا تنشر على المدونة الحيّة قبل مراجعة قائمة التحقق في `docs/TEST-REPORT.md`.

## الإعداد من تخطيط Blogger
| الجزء | الودجت | ما يمكن تعديله |
|---|---|---|
| القائمة العلوية | PageList1 | «الرئيسية» تُضاف تلقائيًا؛ باقي الروابط من **الصفحات** المختارة في الودجت (من نحن، اتصل بنا، …). لا تُنشأ روابط وهمية. |
| أقسام الرئيسية الأربعة | LinkList1 | كل رابط = قسم. الاسم بصيغة `عنوان القسم | وصف قصير`، والرابط `/search/label/اسم_التصنيف`. أضف حتى 4 أو أكثر؛ تُحمَّل المقالات من خلاصة التصنيف. |
| الشريط الجانبي | PopularPosts1, Label1 | العنوان وعدد العناصر. لا يظهر في الرئيسية لتبقى الواجهة نظيفة. |
| التذييل | HTML1, PageList2, Label2 | نص التعريف، روابط الصفحات القانونية، الأقسام. |
| الألوان | القالب ← تخصيص | الكحلي والأزرق والسماوي. |

القيم الافتراضية للأقسام الأربعة (الذكاء الاصطناعي، الهواتف والأجهزة، البرمجة والتطوير، الأمن الرقمي) **اقتراحات قابلة للتعديل**؛ إن لم يوجد التصنيف يظهر القسم بحالة فارغة عربية.

## الصفحات المطلوبة
أنشئ من Blogger ← الصفحات: من نحن، اتصل بنا، سياسة الخصوصية، اتفاقية المستخدم، إخلاء المسؤولية، ثم أضفها في ودجت PageList1 (القائمة) وPageList2 (التذييل).

## الشعار
الرمز الأصلي مضمَّن كما هو (قصّ للهامش الشفاف وتصغير فقط) ويُتبع مباشرة بالنص `arcodo` ليُقرأ **Farcodo** دون حرف F إضافي. لا إعادة رسم ولا تلوين.
