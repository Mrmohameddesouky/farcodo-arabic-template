## إدارة القالب من Blogger ← التخطيط (Layout)
اللغة الأساسية: كل ما يُحرَّر نصيًا يُكتب في أداة **HTML/JavaScript**. الأسطر بصيغة `مفتاح=قيمة`، والسطر الذي يبدأ بـ `#` تعليق. المفاتيح بالإنجليزية لأنها صيغة إعداد لا واجهة للزوار.

| الجزء | الأداة | ما يمكن تحريره |
|---|---|---|
| القائمة العلوية | LinkList2 «القائمة الرئيسية» | الاسم والرابط. القوائم المنسدلة: ابدأ اسم العنصر الفرعي بـ `- ` (مستوى) أو `-- ` (مستويان). «الرئيسية» ثابتة فلا تكرار. |
| روابط التواصل (رأس/تذييل) | LinkList3 / LinkList4 | اسم الرابط ورابطه؛ الأيقونة تُختار تلقائيًا من النطاق (فيسبوك، إكس، إنستغرام، يوتيوب، لينكدإن، تيليجرام، واتساب، تيك توك، بريد، RSS، وإلا رمز رابط). الفارغ لا يظهر. |
| الشعار واسم الموقع | HTML3 «الشعار واسم الموقع» | `logo=` رابط صورة، `name=` نص، `alt=`. الفارغ = شعار فاركودو الأصلي. |
| اللافتة الرئيسية | HTML2 «اللافتة الرئيسية» | `badge` `heading` `description` `button1` `button2` (بصيغة `النص \| الرابط`) `image` `alt` `align=right/center` `posts=show/hide` (إخفاء شبكة أبرز المقالات). للإخفاء: `hidden=yes` أو احذف الأداة. |
| أقسام الرئيسية | قسم `homesections` (HTML4–HTML7 افتراضيًا) | كل أداة = قسم. **العنوان = عنوان الأداة.** المفاتيح: `label` (التصنيف؛ بدونه تُعرض أحدث المقالات) `subtitle` `count` (1–12) `layout=grid/list/compact` `more` (نص الرابط أو `none`) `url` `hidden=yes` `empty=show`. |
| تذييل الصفحات | PageList2 «روابط مهمة» | اختر **صفحاتك الحقيقية** (من نحن، اتصل بنا، الخصوصية، الشروط، إخلاء المسؤولية). |
| الشريط الجانبي / تذييل | PopularPosts1, Label1, HTML1, Label2 | عناوين وإعدادات Blogger المعتادة. |
| الألوان والعرض والاستدارة | القالب ← تخصيص | الكحلي والأزرق والسماوي وخلفية التذييل وعرض المحتوى واستدارة البطاقات. |

### إضافة قسم جديد للرئيسية (بلا تعديل الكود)
لا يفرض القالب أقسامًا أو تصنيفات افتراضية ثابتة. لإضافة الأقسام الخاصة بموقع المشتري: التخطيط ← قسم `homesections` ← **إضافة أداة** ← HTML/JavaScript ← اكتب عنوان القسم، وفي المحتوى:
```
label=اسم التصنيف
subtitle=وصف قصير
count=6
layout=list
```
الترتيب بالسحب والإفلات، والحذف بحذف الأداة. إذا لم توجد مقالات في التصنيف، يبقى القسم ظاهرًا مع رسالة عربية بدل اختفائه بصمت. وعند فشل الطلب تظهر رسالة عربية مع زر «إعادة المحاولة».

الروابط في الإعدادات تقبل: `https://` أو `/` أو `#` أو `mailto:` أو `tel:` فقط.

## التثبيت
1. خذ نسخة احتياطية من القالب الحالي. 2. القالب ← الاستعادة ← ارفع `farcodo-arabic-template.xml`. 3. عدد مقالات الصفحة الرئيسية = 9. 4. انتبه: أداة `LinkList1` القديمة (أقسام الرئيسية) استُبدلت بأدوات HTML؛ سيطلب Blogger حذف الأداة القديمة.
5. أضف أدوات أقسام الصفحة الرئيسية والتصنيفات التي تناسب محتوى الموقع؛ لا توجد أسماء أقسام إلزامية داخل القالب.
